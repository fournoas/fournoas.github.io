VirtualBox VBoxUSBMon 和 usbipd-win 冲突

作者 Fournoas 写于 2026年7月31日 发布在 
  • Using

今日通过 WinGet 升级 VirtualBox 7.2.14，安装失败。退回安装老版本 7.2.12，依旧安装失败。查看安装日志，发现问题出在启动 VBoxUSBMon 服务失败：

VBoxInstallHelper: *** Error: Starting service 'VBoxUSBMon' failed: VERR_UNRESOLVED_ERROR (1058 / 0x422)
MSI (s) (D4!70) [09:54:46:712]: Closing MSIHANDLE (1754) of type 790531 for thread 8304
VBoxInstallHelper: ServiceControl: Handling done (rc=VERR_UNRESOLVED_ERROR)
MSI (s) (D4:8C) [09:54:46:713]: Closing MSIHANDLE (1744) of type 790536 for thread 19532
CustomAction ca_VBoxUSBMonDrvStart returned actual error code 1603 (note this may not be 100% accurate if translation happened inside sandbox)

联想到前几天安装 usbipd-win，当 VirtualBox 虚拟机正在运行时，会安装失败，必须关闭虚拟机才能安装。我就怀疑这俩家伙有冲突。果然，在卸载 usbipd-win 后，重新安装 VirtualBox 成功。

另外，在安装 VirtualBox 前，可以先用 sc stop usbipd 命令停止 usbipd-win 服务，应该也可以。这回懒得测试，下次试试看吧。
