2026年11月4日 反 Vibe Coding 范式

首先明确本文所使用的 Vibe Coding 概念的定义。本文中，它指开发者主要通过自然语言向 AI 描述需求、提出修改意见和反馈结果，以驱动 AI Agent 编程；开发者主要负责需求表达和结果评估，注意力从代码转向与 AI 的自然语言交互，具体实现更多交由 AI 自主完成。随着概念流行，出现了将所有 AI 辅助编程都归入 Vibe Coding 的倾向，这会模糊不同 AI 编程模式的边界，也易混淆性质不同的实践。因此，下文所称 Vibe Coding 仅指此义。

2026年8月6日 如何在 Coding Agent 中使用 agent-browser
本文涉及的问题是因为我的环境非主流引起的。按照官方文档安装使用不存在以下问题。

关于 agent-browser 工具，可以先看看 AI 是如何介绍的：

agent-browser 是一个面向 AI Agent 的浏览器自动化 CLI 工具，让大模型能够像人一样操作网页：打开页面、读取内容、点击按钮、填写表单、截图、处理登录状态等。

不像传统 Playwright/Selenium 经常需要解析庞大的 DOM，它通过 snapshot 输出精简的无障碍树，并给元素分配引用，例如 @e1、@e2，Agent 可以直接操作这些引用，减少上下文消耗。

简单地说，就是一个操作浏览器访问网站的工具，最大的特点是节省 Token。

2025年3月12日 为什么说鼓吹零基础 AI 编程的都是骗子
